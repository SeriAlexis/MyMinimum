# Мой минимум — календарь и трекер.

Минималистичное приложение с трекингом базовых вещей: сон, душ, работа, приёмы пищи. С заметками и планами на день.

## 🚀 Демо
[Ссылка на GitHub Pages](https://serialexis.github.io/MyMinimum/)

## 🛠️ Технологии
- HTML5, CSS3 (Flexbox, Grid)
- JavaScript (ES6)
- LocalStorage (хранение данных)

## 📦 Функционал
- Календарь с девятью неделями, текущий месяц в центре
- Отметка привычек (чекбоксы) для каждого дня
- Цветовая индикация выполненных привычек в ячейках
- Блоки приёма пищи (завтрак, обед, ужин) с цветовой индикацией
- Заметки и планы на день с сохранением в LocalStorage
- Адаптивный дизайн

## 🧪 Запуск
Скачайте папку проекта и откройте `index.html` в браузере.
