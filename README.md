# Мой минимум — календарь и трекер привычек

**Авторский дизайн и разработка**  
Минималистичное PWA-приложение для ежедневного отслеживания базовых привычек: сон, душ, работа, приёмы пищи. С заметками и планами на день. Данные сохраняются локально на устройстве.

## 🚀 Демо
Живая версия доступна на GitHub Pages:  
👉 [serialexis.github.io/MyMinimum](https://serialexis.github.io/MyMinimum/)

## ✨ Особенности

- **Установка как приложение (PWA)**: можно добавить на главный экран телефона и пользоваться как нативным приложением.
- **Интуитивный календарь**: 9 недель, текущий месяц в центре, горизонтальная прокрутка.
- **Гибкое отслеживание**: отмечайте привычки (сон, душ, работа) и приёмы пищи.
- **Визуальная обратная связь**: цветовые градиенты и индикаторы для каждого дня.
- **Личные заметки и планы**: всё сохраняется в localStorage браузера.
- **Адаптивный дизайн**: удобно на телефонах, планшетах и десктопах.

## 🛠️ Технологии

- **Frontend**: HTML5, CSS3 (Flexbox, Grid), JavaScript (ES6)
- **PWA**: манифест, сервис-воркер
- **Хранение данных**: LocalStorage

## 🧪 Запуск проекта локально

1. Склонируйте репозиторий или скачайте папку с проектом.
2. Откройте файл `index.html` в вашем браузере.

## 💎 Дизайн

Всё визуальное оформление, включая иконку приложения, создано мной с нуля в Canva. Иконка разработана с учётом PWA-стандартов (maskable), чтобы отлично выглядеть на домашнем экране любого устройства.
